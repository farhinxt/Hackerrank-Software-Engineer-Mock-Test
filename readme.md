## Included Problems & Solutions

### 1. Valid Transactions (Intermediate)

* **Score:** 75 / 75 (100%)


* **Skills Tested:** Arrays, Binary Search, Prefix Sum


* **Description:** Finds the longest contiguous subarray of banking transactions that the bank can fully process without its capital dropping below zero, prioritizing the smallest starting index on ties. Implemented in **Python 3** using a Prefix Sum array combined with a Sparse Table for efficient Range Minimum Queries (RMQ) and binary search ($O(N \log N)$ time complexity).

### 2. Add to Subsequence (Basic)

* **Score:** 50 / 50 (100%)


* **Skills Tested:** Arrays, Greedy, Hashing, Implementation


* **Description:** Determines the minimum number of operations required to make all elements of an array distinct by selectively adding values to subsequences. Implemented in **C** using sorting, frequency analysis, and bit-capacity doubling.
